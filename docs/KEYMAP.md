# FreeFalcon keyboard map

Generated by `tools/ff_keymap.py` from `keystrokes.key` (the file the game loads; see the script header).
458 bindings, 25 groups. Program data, not documentation: where a manual disagrees, this wins.

**Linux port keys handled before the key file** (`src/ffviper/main_linux.cpp`): F11 fullscreen;
F5 in the UI quick-launches Instant Action; in the sim, Shift+Num8/4/6/2 select the front/left/right/down
2-D cockpit panel **and are still passed to the sim**, where the key file binds them to DMS up/left/right/down,
so a keyboard DMS press also flips the 2-D panel (backlog FF-KEYPANEL-1). Esc never quits the app.
